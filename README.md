# Local AI Notetaker MVP

A local-first AI notetaker. Notes are captured, stored, and processed entirely on your own machine — nothing is sent to a third-party service.

## Status

Early MVP. The implementation stack has not been chosen yet; this repo currently holds documentation only.

## Goals

- Capture notes quickly and store them locally in a plain, portable format.
- Summarize, tag, and search notes using a locally-run model.
- Keep everything offline-capable and privacy-preserving by default.
